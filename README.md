# 後漢書集解 閱讀前端

把[維基文庫《後漢書集解》](https://zh.wikisource.org/wiki/後漢書集解)的整理本（王先謙集解，長沙王氏虛受堂刻本，慶應義塾大學圖書館藏）按「第 N 冊 PDF 第 M 頁」排成一個純靜態的閱讀站：正文、李賢注與集解、各卷後的黃山《校補》，同掃描原圖逐頁對照。

在線閱讀：<https://houhanshujijie.daizhige.org/>

## 使用

```sh
python3 tools/build.py                  # 生成 site/data/（只用標準庫，一兩秒）
python3 -m http.server -d site 8765     # 然後打開 http://127.0.0.1:8765/
```

`site/` 是發佈產物，已隨版本庫提交，克隆後不必構建即可直接部署到任何靜態託管。構建時會順帶把整個站打成 `site/full-site-download.zip`（不入版本庫），部署後可從 `/full-site-download.zip` 下載。

推到 GitHub 後，在 Settings → Pages 把 Source 選為 **GitHub Actions**，`.github/workflows/pages.yml` 會在每次推送 `main` 時重新構建並發佈 `site/`（含離線包）。

底稿有了新的校對進度後：

```sh
python3 tools/import_drafts.py          # 從 ../jinshujiaozhu 更新 .src/pages/ 和 .src/book.json
python3 tools/build.py
```

## 結構

| 路徑 | 內容 |
| --- | --- |
| `.src/pages/NN.wiki` | 第 NN 冊各頁的 wikitext，即維基文庫 `Page:` 頁面原樣，以 `〔第N頁〕` 分頁 |
| `.src/book.json` | 卷目（卷首、紀、列傳、續漢志共 136 篇）、各卷的冊次與頁碼範圍、校補起始頁、30 冊掃描圖地址 |
| `.src/variants.json` | 檢索用的繁簡、異體字組（`tools/make_variants.py` 由 Unihan 生成） |
| `tools/import_drafts.py` | 從整理底稿的工作目錄導入上面兩項，不聯網 |
| `tools/build.py` | 解析 wikitext，輸出每卷一個 JSON 和檢索用文本 |
| `site/` | 發佈產物。前端 `index.html`、`style.css`、`app.js`（無依賴、無構建）和 `tools/build.py` 生成的 `data/` |

## 轉換規則

- 卷的劃分和頁碼範圍與維基文庫各卷子頁的 `<pages from= to=>` 一致，正文之後連著該卷的《校補》。郡國志五分上下，併為一篇。
- 底稿只用到很少幾種標記：`{{*|…}}` 是雙行小注（李賢注、集解；校補裡是黃山按語），`{{c|…}}`、`{{right|…}}` 是卷題和撰人，`* / ** / ***` 是目錄的層級。`build.py` 遇到不認識的標記會報錯停下，不會悄悄漏字。
- 與維基文庫拼接各頁的方式相同：下一頁的文字直接接在上一頁的段落後面，頁碼標在行內；只有另起標題、卷題或 `{{nop}}` 才分段。
- 檢索以「某頁的一段」為單位，正文、注文一併檢索，命中可以跨過正文和注文的邊界。
- 「本卷綱目」的一級是卷題和校補，取自底稿；二級（紀裡的紀年、傳主、論贊）是按行文慣例猜的，只為導航方便，有漏有誤，沒有句讀、不分段的卷基本沒有二級。

## 來源與可靠性

- 文字取自維基文庫，依 CC BY-SA 授權。全書 5,432 頁中目前只有 43 頁已對照原圖校對（頁碼旁標「校」），其餘是把電子文本按頁對位而成的初稿，錯字、脫文和分頁錯位都可能有，引用前請核對掃描原圖。
- 卷首各篇和一部分卷原文沒有句讀，照底稿原樣，不另加標點。
- 字形從底本（如 `㠯`、`尙`、`卽`），檢索時異體互通。
- 卷內有 77 頁沒有底稿（多為卷末空白頁），顯示為空白；第 30 冊末的著作權執照和板權頁不屬於任何卷，沒有收入。
- 第 10 冊第 52 頁（卷三十下）慶應本掃描拍重了，缺這半葉。維基文庫在索引頁的 `<pagelist>` 裡把它換成他本的頁（`SSID-13358080 後漢書集解 卷30-34.pdf` 第 52 頁），這裡照樣處理：文字取自底稿的 `_hold/`，掃描圖和「在維基文庫校對」的鏈接都指向他本，頁碼旁標「他本」。這類頁登記在 `tools/import_drafts.py` 的 `ALT` 裡。
- 掃描原圖不在版本庫內，閱讀時從維基共享資源在線載入。
